# Post-it

İşleri, başlama eşiklerini, koşulları ve iş zincirlerini ölçen kişisel gün panosu. Telefona uygulama olarak eklenebilen bir PWA.

Kodda kişisel veri yoktur. Veriler cihazda ve (bağlanırsa) kullanıcının kendi Google Drive'ındaki `post-it-pano.json` dosyasında tutulur. Uygulama yalnızca `drive.file` iznini ister, yani sadece kendi oluşturduğu dosyayı görebilir.
